# Web_Security

Writeups and PoCs for web application vulnerabilities, based on PortSwigger Web Security Academy labs.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Topic](https://img.shields.io/badge/topic-Web%20Security-red)
![Topic](https://img.shields.io/badge/topic-Web%20Pentesting-orange)

This repo is an ongoing collection of my writeups and PoCs while learning and practicing web application security — covering vulnerabilities like SQL Injection, XSS, CSRF, SSRF, Path Traversal, Authentication flaws, and more (mostly based on PortSwigger Web Security Academy labs).

New writeups are added regularly as I keep solving and documenting more labs.
