## 📖 About

This repo is an ongoing collection of my writeups and PoCs while learning and practicing **web application security** — documenting how vulnerabilities work, how to exploit them, and how to fix them. Mostly based on **PortSwigger Web Security Academy** labs.

> New writeups are added regularly as I keep solving and documenting more labs. ⚡

<br>

## 📂 Repo Structure

```
Web_Security/
└── PortSwiggerLabs/
    └── <vulnerability-name>/     → writeup + PoC for each lab
```
